これは何？

本ドキュメントは、熊野寮の荷物管理アプリ「POKKE」のセットアップ方法を示したマニュアルです。
万が一、端末が紛失・破損などの不測の事態に陥った際、情報委員会が速やかにシステムを初期状態から元の運用状態に復旧させることを目的としています。

セットアップ手順

Step 01

タブレットの選定・購入

POKKEの稼働に適したタブレットを選び、購入してください。

必須要件 (Requirements)

  • ▪ 約10インチの画面サイズ
    (小さいと誤タップが多く、操作しにくくなります)
  • ▪ 1080p（フルHD）以上の解像度
  • ▪ Type-C 充電ポート

推奨要件 (Better to have)

  • ▪ 自立スタンド or 専用ケース付き
    (事務室のカウンターに安定して設置するため)
  • ▪ 非接触充電（ワイヤレス充電）対応
    (常時抜き差しする充電口は物理的に最も壊れやすいため、ワイヤレス化を強く推奨)
Step 02

タブレットの初期設定

ハードウェアを起動し、POKKE専用機としてのOS設定を施します。

  1. 1

    初回起動セットアップ

    画面の指示に従い、一般的な初期設定（言語・時間設定など）を終わらせます。
  2. 2

    Wi-Fi回線の接続・保存

    ※ 事務室に通っているブロックのWi-Fiを借りてください。回線を接続・保存します。 POKKEの常時データ連携には安定したネットワーク環境が必須です。
  3. 3

    ロック画面の無効化（超重要）

    事務室の利用者がスムーズに操作できるよう、OS設定のセキュリティ/画面ロックから「スワイプのみ」または「なし」に設定します。電源ボタンを押したらパスコードなしで即座にホーム画面が開く状態が理想です。
Step 03

テプラによる物理的な表示

事務室からの「誤持ち出し」や「誤操作」を防ぐため、端末を物理的にマーキングします。

貼付内容 1：端末の正体明示

「POKKE 持ち出し禁止」

など、一目で事務室の共用備品であることが分かるテプラを、端末の背面にデカデカと貼ってください。

貼付内容 2：インターフェースの明示

・電源ボタンの位置を示すラベル（矢印等）

・充電の差し込み口の場所を示すラベル

機械に不慣れな寮生でも迷わず電源を入れたり、充電ケーブルを正しく挿せるように補助します。カメラやディスプレイ表示領域にテプラが被らないよう留意してください。

Step 04

POKKE アプリのインストール

テスト配信プラットフォーム「DeployGate」を介してアプリを配信します。

▶

開発者の向後に「タブレットが破損または新調された旨」を連絡し、インストール用リンクの共有を依頼します。

公式連絡フロー (Official Contact)

GitHubのPOKKEリポジトリIssuesにアクセスし、アカウント KogoTakuma をメンションして状況説明のIssueを作成してください。

https://github.com/kumano-dormitory/pokke-android-2/issues
▶

向後から「DeployGate インストール用のリンク」と「合言葉」が返信・共有されるのを確認する。

  1. 1

    向後からもらったリンクをPCなどから開く。

  2. 2

    向後から伝えられた合言葉を入力する。

  3. 3

    「実機でインストール」の横にあるQRコードをタブレットで読み取る。

  4. 4

    開いたページで「Google Playが使えない場合」を選ぶ。

  5. 5

    DeployGateアプリをインストールする。

  6. 6

    DeployGateアプリからPOKKEをインストールする。

※注意: Androidの設定で「不明なアプリのインストール」の許可を求められた場合は、指示に従って使用中のブラウザまたはDeployGateアプリに権限を付与してください。
Step 05

ローカルデータの初期同期

アプリをサーバーデータベースと同期させ、最新の寮生データ・荷物データを反映させます。

1. 管理者画面の解放

POKKEアプリ内の管理者メニューに入ります。

※通常、アプリ設定内の特定の歯車アイコン、もしくは画面端の長押しからパスワード入力欄が解放されます。

PASS: PassworD

2. 同期ボタンの実行

① 寮生情報の同期 EXECUTE
② 荷物データの同期 EXECUTE

画面内の上記2つの同期ボタンを順に押してください。「同期完了」を示すトーストやインジケータが消えるまで待ちます。サーバーから最新のマスターデータがローカルDBに同期されれば、全てのセットアッププロセスが完了します。

EMERGENCY PROCEDURES

向後に連絡がつかない場合の対応方法

もし開発者（向後）との連絡が途絶えている間に復旧が必要となった場合は、以下の手順に従ってAndroid Studioから直接ソースコードをビルドし、実機（タブレット）にアプリを転送してください。

01

Repo Clone

リポジトリからソースコードをクローンします。

https://github.com/kumano-dormitory/pokke-android-2
02

IDE Install

Android Studioを開発PCにインストール、起動します。

Android SDK / Build Tools
03

API Key Config

プロジェクト内の環境変数 POKKE_API_KEY をセットします。

キーは kumapticon の環境変数に設定されているものと同じ値を設定。（サーバーにsshして確認してください）
04

Build & Run

タブレットのUSBデバッグを有効化し、PCと有線接続してビルド＆インストールを実行します。

Build variant: release / debug

実機テスト用TIPS：USBデバッグの有効化手順

Android Studioからタブレットへ直接アプリをビルド転送するには、タブレット側で開発者向けオプションを解放する必要があります：

  1. タブレットの「設定」アプリを開く。
  2. 「デバイス情報」（または「端末情報」）に移動する。
  3. 項目内にある「ビルド番号」を連続で7回タップする。
  4. 「これで開発者になりました」と表示されたら、1つ前の画面に戻り、「システム」＞「開発者向けオプション」を開く。
  5. 「USBデバッグ」をONにし、PCと接続してビルドを実行する。
